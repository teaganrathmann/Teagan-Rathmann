# About This Project
This project is a final project. I will be creating a portfolio using my HTML and CSS skills. I will be creating a responsive multi-page portfolio website that allows anyone viewing my site to get to know me. This project will be created using HTML and CSS and it will have a complete and valid HTML as well as valid and functioning CSS that is correctly displayed on every single page. The website is designed to showcase my background, skills, projects, photography, and creative work throughout my academic and professional career. This site demonstrates responsive design principles, semantic HTML structure, accessibility improvements, navigation systems, and modern CSS layout techniques including Flexbox and CSS grid. This project does not include Javascript.
